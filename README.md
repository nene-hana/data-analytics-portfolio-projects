An end-to-end data analytics project analyzing retail customer shopping behavior - from raw data to interactive dashboard -using Python, PostgreSQL, and Power BI.

---

## 📌 Overview

A leading retail company wants to better understand its customers' shopping behavior to improve sales, customer satisfaction, and long-term loyalty. This project analyzes **3,900 customer records** across demographics, product categories, purchase patterns, and sales channels to answer key business questions and surface actionable insights.

---

## 🗂️ Dataset

**Source:** Customer Shopping Behavior Dataset  
**Size:** 3,900 rows × 19 columns  
**Key Features:** Customer ID, Age, Gender, Item Purchased, Category, Purchase Amount (USD), Location, Size, Color, Season, Review Rating, Subscription Status, Shipping Type, Discount Applied, Promo Code Used, Previous Purchases, Payment Method, Frequency of Purchases

---

| Tool | Purpose |

| # | Question |

| Q4 | Compare average purchase amounts between Standard and Express Shipping |

## 🚀 How to Run

**1. Clone the repository**
```bash
git clone https://github.com/nene-hana/data-analytics-portfolio-projects.git
cd data-analytics-portfolio-projects/Customer-Behavior-Data-Analysis
```

**2. Set up PostgreSQL**
- Create a database named `customer_behavior`
- Update credentials in the notebook using environment variables:
```python
import os
from urllib.parse import quote_plus
password = quote_plus(os.environ.get('PG_PASSWORD'))
```

**3. Run the Jupyter Notebook**
- Open `customer_behavior_analysis.ipynb`
- Run all cells to clean data and load it into PostgreSQL

**4. Run SQL queries**
- Open `customer_query_solutions.sql` in pgAdmin or any PostgreSQL client
- Execute queries against the `customer_behavior` database

**5. View the Dashboard**
- Open `customer_behavior_dashboard.pbix` in Power BI Desktop
- Connect to your local PostgreSQL instance if prompted

---

## 🔐 Security Note

Database credentials are **not hardcoded** in this project. Use environment variables to store sensitive information before running locally.
